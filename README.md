# Репозиторий документации СМИБ — Университет Satbayev

Репозиторий предназначен для ведения документированной информации системы
менеджмента информационной безопасности (СМИБ) в соответствии с требованиями
пункта 7.5 СТ РК ISO/IEC 27001-2023.

## Структура

| Каталог | Уровень иерархии | Содержание |
|---|---|---|
| `01-politika/` | Уровень 1 | Политика ИБ верхнего уровня |
| `02-chastnye-politiki/` | Уровень 2 | Частные (тематические) политики |
| `03-procedury/` | Уровень 3 | Процедуры и регламенты |
| `04-instrukcii/` | Уровень 4 | Инструкции, шаблоны, чек-листы |
| `05-zapisi/` | — | Шаблоны записей (свидетельств) |

## Порядок внесения изменений

1. Изменения вносятся только через ветку и запрос на слияние (merge request).
2. Прямая запись в ветку `main` запрещена (ветка защищена).
3. Каждый запрос на слияние проходит рецензирование назначенным рецензентом.
4. Описание коммита должно содержать суть и причину изменения.
5. Утверждённая редакция помечается аннотированным тегом `vN.N`.
